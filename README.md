# XEROX-catalyst-
XEROX answers one question in milliseconds: is this message, call, link, QR code or webpage TRUE — or a scam? It fuses five channels into one explainable TRUE/CAUTION/FALSE verdict and keeps genuine bank OTPs SAFE. Runs entirely in your browser: no backend, no upload, no build step, works fully offline. Measured at 99.4% precision across 8/8 tests.
